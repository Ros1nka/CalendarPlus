# План: Разметка календаря

## Цель
Создать разметку календаря с кликабельными днями со скруглёнными углами, недели на отдельных строках, видимым месяцем по центру и 2 неделями следующего месяца.

## Изменяемые файлы

### 1. `CalendarPlus/Models/DateCell.cs`
- Добавить полные свойства с `[ObservableProperty]`: `Date`, `Day`, `Month`, `Year`, `IsCurrentMonth`, `IsToday`, `IsSelected`
- Конструктор принимает `DateTime`, `bool isCurrentMonth`, `bool isToday`
- Наследовать `ObservableObject`

### 2. `CalendarPlus/ViewModels/MainWindowViewModel.cs`
- Свойства: `CurrentMonthDate` (текущий отображаемый месяц), `HeaderText` (название месяца и год), `Weeks` (`ObservableCollection<ObservableCollection<DateCell>>`)
- Метод `GenerateCalendar()`: генерирует 6 строк по 7 дней (42 дня), начиная с первого дня недели первого числа текущего месяца
- Команды: `PreviousMonthCommand`, `NextMonthCommand`, `SelectDay(DateCell)`
- Автовыделение сегодняшнего дня

### 3. `CalendarPlus/Views/MainWindow.axaml`
- **Шапка**: навигация ← Месяц Год → (StackPanel с кнопками и TextBlock)
- **Заголовки дней недели**: Sun, Mon, Tue, Wed, Thu, Fri, Sat (UniformGrid, 7 колонок)
- **Разделитель**: тонкая линия
- **Сетка календаря**: ScrollViewer → StackPanel → ItemsControl (Weeks)
  - Каждый элемент недели: StackPanel (Orientation=Horizontal) → ItemsControl (дни)
  - День: Border с `CornerRadius="8"`, `Classes="day-cell"`, `Classes.Contains.selected="{Binding IsSelected}"`
  - Внутри Border: TextBlock с текстом дня
- **Стили (Window.Styles)**:
  - `Border.day-cell` — скругление, фон, отступы
  - `Border.day-cell:pointerover` — подсветка при наведении
  - `Border.day-cell.selected` — выделенный день (акцентный цвет)
  - `TextBlock.day-cell-text.other-month` — серые дни другого месяца
  - `TextBlock.weekday-header` — заголовки дней недели
  - `Button.nav-button` — кнопки навигации

### 4. `CalendarPlus/Views/MainWindow.axaml.cs`
- Добавить обработчик `DayCell_Tapped` для выбора дня (вызывает `SelectDayCommand`)

## Структура данных
```
Weeks (ObservableCollection<ObservableCollection<DateCell>>)
├── Week 0: [Day1, Day2, ..., Day7]
├── Week 1: [Day8, Day9, ..., Day14]
├── Week 2: [Day15, Day16, ..., Day21]
├── Week 3: [Day22, Day23, ..., Day28]
├── Week 4: [Day29, Day30, ..., Day35]  ← часть след. месяца
└── Week 5: [Day36, Day37, ..., Day42]  ← часть след. месяца
```

## Верификация
1. Запустить приложение (`dotnet run` или через Rider)
2. Проверить: отображается текущий месяц по центру, 2 строки снизу — дни следующего месяца
3. Дни текущего месяца — яркие, дни другого месяца — серые
4. Клик по дню выделяет его акцентным цветом
5. Кнопки ← → переключают месяц
6. Сегодняшний день выделен жирным шрифтом
7. Все дни имеют скруглённые углы
8. Каждый день кликабелен (подсветка при наведении)
